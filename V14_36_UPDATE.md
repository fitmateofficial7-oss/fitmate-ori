# FitMate v14.36 – Jogging Map Final Cleanup

This release finalizes the FitMate jogging map presentation.

## Main fixes
- Reduced visual clutter in the cartoon map.
- The main jogging map now hides external map tiles before any GPS points exist, so the empty state no longer shows a faded Indonesia-wide basemap.
- Reduced decorative overlay density and opacity so the map looks cleaner and more professional.
- Simplified the top identity badges and made them less dominant.
- Refined the empty GPS state card to be smaller, cleaner, and easier to read.
- Reduced the main map height so the statistics area becomes visible sooner without feeling oversized.
- Preserved the branded FitMate route glow, gradient trail, custom start/finish markers, and share-card styling.
