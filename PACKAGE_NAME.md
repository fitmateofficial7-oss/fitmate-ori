# FitMate Package Name

Android package name / application ID:

`com.growsia.fitmate`

Capacitor app name:

`FitMate AI`

The package identifier is configured in `capacitor.config.ts` as:

```ts
appId: "com.growsia.fitmate"
```

When the Android project is generated/synchronized with Capacitor, this identifier should be used as the Android application ID/package name.
