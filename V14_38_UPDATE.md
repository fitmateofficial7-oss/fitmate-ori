# FitMate v14.38 – Bubble Menu Re-centered on Jogging Page

- Restored the floating bubble menu on the Jogging page to the same bottom-center position used on the other FitMate pages.
- Removed the special Jogging-page class override from the floating menu runtime component, so the menu no longer shifts to the bottom-right on `/jogging`.
- All other Jogging features from the previous version remain unchanged.
