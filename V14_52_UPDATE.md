# FitMate AI v1.4.52

## Panduan latihan 2D sekarang bergerak

- Saat pengguna membuka **View Guide**, tampilan default langsung berada pada mode **Animasi**.
- Karakter SVG 2D bergerak halus dari posisi awal ke posisi akhir dan kembali lagi secara otomatis.
- Gerakan alat seperti dumbbell, barbell, kabel, dan ab wheel mengikuti posisi tangan karakter.
- Animasi dibatasi sekitar 30 FPS agar tetap ringan di HP dan laptop.
- Pengguna tetap dapat memilih **Bandingkan**, **Posisi awal**, dan **Posisi akhir**.
- Preferensi aksesibilitas `prefers-reduced-motion` dihormati.
- Tidak ada WebGL, Three.js, model 3D, atau file animasi eksternal yang ditambahkan.
