# FitMate v14.37 – Final Jogging Experience

This release completes the final jogging polish requested after v14.36.

## FitMate mascot map markers
- Replaced generic start and finish markers with custom FitMate mascot-face markers.
- Added START and FINISH labels.
- The active endpoint has a subtle pulse so the current position is easier to find.
- Replaced the emoji-only FitMate Trail badge with a custom mascot face.

## Premium share-card design
- Upgraded the exported jogging card into a more premium social-media layout.
- Added FitMate mascot branding, GPS Activity and Share Ready badges.
- Added a branded energy-trail route area.
- Added icon-based metric cards for distance, pace, time, calories, speed, and elevation.
- Added a cleaner footer with FitMate AI branding and #FitMateTrail.
- Track and uploaded-photo modes remain supported.

## Mobile experience
- Reduced mobile hero and map height.
- Made metric cards more compact and responsive.
- Added sticky jogging controls on mobile for easier pause/resume/finish access.
- Moved the floating bubble menu to the right on the jogging page so it no longer covers the metric cards and controls.
- Improved share preview sizing for mobile screens.
- Simplified history route previews for faster, cleaner rendering.
