# FitMate AI v14.4

## Unified app UI

The eight main signed-in pages now share the same FitMate app shell used by Workout and Nutrition: neutral page background, consistent dark mode, compact headers, softer shadows, aligned form controls, and reduced duplicate desktop navigation.

## Scattered bubble navigation

The navigation bubbles return to an irregular cloud layout. Their positions are deterministic so they feel organic without overlapping on supported mobile and desktop widths. Labels remain horizontal and centered.

## Bubble click sound

Opening, closing, and selecting a navigation bubble now plays a short synthesized bubble sound through the Web Audio API. No external audio file or network request is required. Navigation still works when audio is unavailable or blocked by the browser.
