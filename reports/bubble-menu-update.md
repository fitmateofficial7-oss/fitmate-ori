# FitMate Mobile Bubble Menu Update

## Perubahan

- Panel menu mobile berukuran besar dihapus.
- Navigasi mobile kini memiliki empat menu utama: Beranda, Rencana, Latihan, dan Coach.
- Tombol bulat di tengah membuka lima menu tambahan dalam susunan gelembung: Gerakan, Progres, Nutrisi, Pengaturan, dan Motivasi.
- Tombol tema serta pilihan bahasa tetap tersedia dalam gelembung kecil.
- Menu tidak memakai overlay gelap atau modal layar penuh.
- Klik di luar menu dan tombol Escape akan menutup menu.
- Safe area smartphone dan dukungan layar minimum 320 px tetap dipertahankan.
