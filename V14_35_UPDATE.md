# FitMate v14.35 – Cartoon Jogging Map & Branded Share Upgrade

This release upgrades the free Jogging feature with a more unique FitMate visual identity.

## What's new
- Reworked the jogging map into a more cartoon / playful FitMate style.
- Added a pastel-mint FitMate basemap treatment with decorative park blobs, contour lines, and stylized road curves.
- Kept optional OpenStreetMap tiles, but tinted and softened them so the overall look feels more branded.
- Upgraded the route line into an energy-trail style with glow, gradient stroke, and dotted highlights.
- Added custom start and finish markers.
- Added FitMate Trail and Cartoon Map identity badges to the map.
- Enhanced the empty-state message to explain the live cartoon track behavior.
- Upgraded the exported share card so the track card also uses the new FitMate visual language.
- Fixed the speed metric rendering call in the share card generator.

## Existing free Jogging capabilities preserved
- GPS live tracking
- route line
- distance, duration, pace, speed, calories, elevation, splits
- track or photo share mode
- download and share support
- local persistence and Supabase sync support
